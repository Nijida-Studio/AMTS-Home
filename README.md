# Akari AMTS website

This branch contains the Jekyll website published at `amts.nijida.studio`.
The specification and its maintained documentation remain on the `main`
branch; website pages summarize and link to that source material.

During the initial design phase this site uses
`Nijida-Studio/nijida-theme@themetest`. At the first official launch it will
switch to `Nijida-Studio/nijida-theme@main` together with the other Nijida
sites.
