# Minimal AMTS Space Example

This example shows a minimal conceptual AMTS Space.

```text
ExampleAMTSSpace/
  AMTS/
  Common/
  Projects/
    ExampleProject/
      README.md
      handover.md
      current-work.md
      decisions.md
      session-summaries/
      prompts/
      references/
  Archive/
    Codex/
      2026/
        ExampleProject/
```

The exact physical path is implementation-specific.

For example, a personal installation may use a synced local folder, while a team installation may use a shared repository or hosted workspace.
