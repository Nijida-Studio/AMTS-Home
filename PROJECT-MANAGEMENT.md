# Project Management

This repository uses ODTS as its agile project-development framework.

ODTS is not part of the AMTS specification.

ODTS organizes the work on this repository through Epics, Items, and Tasks. AMTS is the specification being developed in this repository.

## Relationship

- **AMTS**: the specification maintained by this repository.
- **ODTS**: the project-development framework used to plan and track work on AMTS.
- **GitHub Issues**: the practical place where ODTS Epics, Items, and Tasks are created.

## Issue Hierarchy

AMTS work is organized through the ODTS hierarchy:

```text
Epic
  Item
    Task
```

Epics describe broad goals.

Items describe focused work areas below Epics.

Tasks describe concrete work below Items.

## Boundary

ODTS may shape how work is planned, reviewed, and tracked.

ODTS does not define AMTS concepts, terminology, directory layout, startup, shutdown, or compatibility rules.
