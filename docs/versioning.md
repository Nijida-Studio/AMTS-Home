# Versioning

## Current Status

AMTS is currently a draft specification.

Current version:

0.1.0.

## Version Scheme

AMTS should use semantic versioning once compatibility rules are defined:

```text
MAJOR.MINOR.PATCH
```

## Compatibility

Until AMTS reaches version 1.0.0, compatibility is best-effort.

Specification changes should still document:

- what changed
- whether existing AMTS Spaces need migration
- whether existing templates need updates
- whether implementations need changes

## Change Records

User-visible specification changes should be recorded in `CHANGELOG.md`.

Important conceptual decisions should be recorded in `GOVERNANCE.md`, issues, pull requests, or project decision records.
