# Contributing

Thank you for your interest in Akari AMTS.

The specification is written in English.

Issues, discussions, and community material may also use German or Japanese when helpful.

## What Helps

- clarifying specification language
- improving examples
- testing AMTS with real projects
- reporting confusing terminology
- improving Japanese documentation
- contributing Mac developer workflow experience

## Work Tracking

This repository uses ODTS as its agile project-development framework.

GitHub Issues may be structured as ODTS Epics, Items, and Tasks. ODTS organizes the work; AMTS remains the specification being developed.

## Before Proposing Changes

Please check:

- [Specification](docs/specification.md)
- [Glossary](docs/glossary.md)
- [Design Principles](docs/principles.md)
- [Project Management](PROJECT-MANAGEMENT.md)
- [Governance](GOVERNANCE.md)

## Pull Requests

Pull requests should keep changes small and reviewable.

Specification changes should explain:

- what changes
- why it changes
- whether existing AMTS Spaces are affected
- whether templates or examples need updates
