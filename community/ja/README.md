# Akari AMTS 日本語情報

Akari AMTS は Akari Memory Transfer Specification です。

仕様本文は英語で管理されています。この日本語ページは、日本語話者、とくに日本の Mac 開発者に向けた入口として用意しています。

## 概要

AMTS は、AI アシスタントを使った開発や作業で、プロジェクトの文脈、引き継ぎ、判断、作業履歴を整理して保持するための仕様です。

AMTS はアプリケーション、ライブラリ、フレームワークではありません。

AMTS は仕様です。
