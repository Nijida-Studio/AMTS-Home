# Akari AMTS auf Deutsch

Akari AMTS ist die Akari Memory Transfer Specification.

Die Spezifikation selbst wird auf Englisch gepflegt. Dieses Repository soll aber auch deutschsprachige Orientierung bieten, damit Projektentscheidungen, Diskussionen und Community-Beiträge leichter zugänglich bleiben.

## Kurzfassung

AMTS beschreibt, wie Projektwissen für KI-assistierte Arbeit erhalten, strukturiert, übergeben und zwischen verschiedenen Arbeitsumgebungen rekonstruiert werden kann.

AMTS ist keine Anwendung und kein Framework.

AMTS ist die Spezifikation.

Eine konkrete Nutzung der Spezifikation heißt AMTS Space. Eine lokale oder gehostete Instanz davon kann als AMTS-Installation bezeichnet werden.

## Sprachen

- Spezifikation: Englisch
- Projekt- und Community-Material: Deutsch, Englisch und Japanisch
